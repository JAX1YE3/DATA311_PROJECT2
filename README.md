### data/raw

The two source datasets, untouched, exactly as downloaded from Canvas:

- `simulated_commuter_survey_2020_26_messy.csv` — one respondent × one survey year
- `population_addresses_messy.csv` — one person (campus role + current/permanent address)

`analysis/01_clean_data.qmd` reads these two files by these exact names — don't rename them, and don't open/re-save them through Excel or Sheets (that silently changes ZIP codes and other text-formatted columns).

### data/cleaned

Outputs produced by `analysis/01_clean_data.qmd` — never edited by hand, only regenerated by re-rendering the notebook:

- `survey_clean.csv` — cleaned commuter survey
- `population_clean.csv` — cleaned population/address data
- `change_log.csv` — row-level log of every value changed, flagged, or dropped during cleaning
- `population_geocoded.csv` — population data with Nominatim geocoding columns added
- `region_routing_table.csv` — per-region routing/transit numbers, used by the dashboard

### analysis

`01_clean_data.qmd` cleans and documents the two core datasets, following the VDS process (understand the domain → examine the data → write action items → encode decisions in code). Code is hidden on render (`echo: false`); the readable product is the narrative plus the visible change/issue log and address-validation tables. `01_clean_data.html` is the rendered output, committed here so it's viewable without running anything.

Re-render with (requires Quarto installed separately, plus the packages in `requirements.txt`):
```
quarto render analysis/01_clean_data.qmd
```

### dashboard

`Data311_project2_DNDashboard.py` — the Streamlit app: a regional map (population, clickable), a per-region detail panel (preferred transport mix plus walk/drive/bus time, distance, and CO₂e), and a car-cost/CO₂e calculator using real Cal Poly Humboldt permit pricing. Reads `data/cleaned/region_routing_table.csv`.

Run with:
```
streamlit run dashboard/Data311_project2_DNDashboard.py
```

### outputs/figures and outputs/tables

Reserved for exported chart images and summary tables pulled out of the notebook or dashboard for use elsewhere (slides, a written report).
